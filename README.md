## 介绍 / Introduction

Pop up Ciallo every morning.

Ciallo Widget 是一个适用于 Class Widgets 2 的插件，用来在 Class Widgets 2 上显示一条 Ciallo 提示。

### 截图 / Screenshots

<div align="center">

![示例](docs/example.png)

</div>

### 特性 / Features

- 自定义欢迎文本
- 支持切换是否在上课期间显示
- 基于 Class Widgets 插件系统接入

## 安装 / Installation

1. 下载或构建插件文件 `top.purrbyte.ciallo-widget.cwplugin`。
2. 在 Class Widgets 中导入该插件并启用。
3. 按需调整插件设置。

## 使用 / Usage

- **Text**：设置显示的欢迎文本。
- **Display on class or activity**：控制是否在上课/活动期间显示。
